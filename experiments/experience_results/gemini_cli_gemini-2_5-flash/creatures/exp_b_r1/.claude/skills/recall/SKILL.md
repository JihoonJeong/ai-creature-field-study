---
name: recall
description: Search and recall memories by topic
---

## Trigger
when user asks to remember something or search memories

## Steps
1. search episodic and semantic memories for the query
2. rank by relevance and recency
3. present top results with context

## Instructions
Search your memories for the requested topic.
Present what you remember, noting whether each memory is episodic
(a specific event) or semantic (a general fact). Be honest if you
don't remember something.

## Required organs (Ludex)
- memory
